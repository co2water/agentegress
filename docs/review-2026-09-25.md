# Independent reviews, 2026-09-25 and 26

After W1–W3 were built and declared passed by the same AI agent that wrote them, separate AI
reviewer agents — fresh context, read-only access to the repo — checked the work: a code
reviewer, an acceptance auditor that re-derived every claimed number, and a pre-release
privacy/IP auditor over the full git history. Five further code reviews checked the fixes. This
page lists what they found and what changed. Every fix in the first two reviews has a regression
test that fails on the old behaviour, except first-review #12 (a runtime self-check, marked "—");
for the third review, see the note there.
